# 국내주식 추천 (개인용)

투자 기간 키워드(단타 / 3개월 이상 / 6개월 이상 / 1년 이상 / 3년 이상)를 고르면
최근 가격·거래량 데이터를 기반으로 국내 상장종목 5~10개를 추천해주는 개인용 웹앱입니다.

앱스토어에는 올리지 않고, 내 PC에서 서버를 켜고 같은 Wi-Fi의 휴대폰에서
브라우저로 접속해 "홈 화면에 추가"하는 방식(PWA)으로 나만 사용합니다.

**투자 조언이 아닙니다.** 과거 가격/거래량만으로 계산한 정량 스크리너 결과이며,
재무제표나 뉴스, 시장 상황은 반영하지 않습니다. 참고용으로만 사용하세요.

## 실행 방법

1. `start.bat` 파일을 더블클릭하면 서버가 켜집니다. (처음 실행 시 Windows 방화벽이
   "공용/개인 네트워크에서 액세스 허용"을 물어보면 **개인 네트워크(사설망)**만
   체크하고 허용하세요.)
2. 이 PC에서 확인: 브라우저로 `http://localhost:8000` 접속
3. 휴대폰에서 확인: 휴대폰이 PC와 **같은 Wi-Fi**에 연결된 상태에서
   `http://172.30.1.50:8000` 접속 (PC의 IP가 바뀌면 `ipconfig`로 확인해서
   README의 이 주소를 갱신하세요)
4. 휴대폰 브라우저 메뉴에서 "홈 화면에 추가"를 누르면 앱처럼 아이콘이 생깁니다.
5. 서버를 끄려면 `start.bat`이 띄운 검은 창을 닫으면 됩니다.

## 데이터는 어떻게 최신으로 유지되나요?

- 서버가 처음 켜질 때 종목 데이터가 없거나 20시간 이상 지났으면 자동으로
  백그라운드에서 전체 종목 시세를 다시 받아옵니다(약 2~3분 소요, 그동안도
  화면은 뜨고 상단에 "준비 중" 표시가 나옵니다).
- 화면 상단의 "새로고침" 버튼을 누르면 즉시 강제로 다시 받아옵니다.

## 추천 로직 (요약)

재무제표(PER/PBR/배당 등)는 로그인 없이 안정적으로 받을 무료 소스가 없어서,
**가격·거래량 히스토리 기반 기술적/정량 지표**로만 스크리닝합니다.

| 키워드 | 핵심 기준 |
| --- | --- |
| 단타 | 최근 변동성 + 거래량 급증 + 단기(5일) 모멘텀 |
| 스윙 | 120일 우상향 추세를 유지하면서 최근 20일 스윙 저점(눌림목) 부근까지 조정받은 종목 — 스윙 저점 매수 → 스윙 고점 매도 구간 수익을 노리는 전략 |
| 3개월 이상 | 20일선이 60일선 위 상승 추세 + 60일 수익률 |
| 6개월 이상 | 60일선이 120일선 위 중기 추세 + 120일 수익률 |
| 1년 이상 | 1년 수익률 + 최대낙폭(MDD) 방어력 |
| 3년 이상 | 3년 수익률 + 낮은 변동성/낙폭 (안정성 위주) |

**공통 유동성 필터**: 키워드와 상관없이, 최근 5거래일 평균 거래대금이 30억원
미만이거나, 평균 거래량이 하루 400만주 미만이거나, 최근 거래량이 60일 평균의
30% 밑으로 식어버린 종목은 추천에서 아예 제외합니다. 추세가 아무리 좋아 보여도
실제로 사고팔기 어려우면 의미가 없기 때문입니다. 각 카드의
"최근거래대금"·"최근거래량"·"거래량비" 수치로 직접 확인할 수 있습니다.

**단타·스윙 전용 추가 필터**: 최근 6개월 안에 고점 대비 -20% 이상 조정과
저점 대비 +20% 이상 반등이 둘 다 있었던(=오르내림 폭이 충분한) 종목 중에서,
최근 1년 수익률이 플러스이고 현재가가 120일 이동평균선 위에 있는(=꾸준히
우상향해온) 종목만 남깁니다. 변동성은 크지만 방향성 없이 횡보하거나
장기 하락 추세인 종목을 걸러내기 위한 조건입니다.

각 지표를 종목 풀(유동성 상위 약 300개) 안에서 표준화(z-score)한 뒤
가중합으로 점수를 매겨 상위 5~10개를 보여줍니다.

## 프로젝트 구조

- `backend/` — FastAPI 서버. `FinanceDataReader`로 KOSPI/KOSDAQ 시세를 받아
  로컬 캐시(`backend/cache/*.parquet`)에 저장하고, `/api/recommend` 등을 제공.
- `frontend/` — React + Vite PWA. `npm run build`로 만든 `frontend/dist`를
  백엔드가 그대로 서빙합니다(별도 웹서버 불필요).

## 개발 모드로 프론트만 따로 손보고 싶을 때

```bash
cd backend
.\venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000
```

```bash
cd frontend
npm run dev
```

`frontend`를 코드 수정할 때는 `npm run dev`(핫리로드)로 확인하고,
실제로 쓸 때는 `npm run build` 후 `start.bat`으로 실행하세요.
